# Feature specs

Specs live here, grouped by module:

`.ai-context/specs/<module>/<feature-slug>.spec.md`

Do not use `.ai-context/specs/<slug>/spec.md`.

These drafts state business behaviour and Given / When / Then criteria. They do not define HTTP contracts. API design waits until the open questions in `.ai-context/BRD.md` are closed and a spec is submitted for Gate 1.

Gate review for every module is `.ai-context/GATE.md`.
