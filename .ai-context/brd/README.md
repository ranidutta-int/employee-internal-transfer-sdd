# Feature BRDs

Feature BRDs live here, grouped by module:

`.ai-context/brd/<module>/<feature-slug>.brd.md`

The authoritative baseline is `.ai-context/BRD.md` version 0.3.

| Companion | Path |
| --- | --- |
| Member journey and edge cases | `end-to-end-journey.md` |
| Pitch demo — one move start to finish | `pitch-demo-journey.md` |
| Pages and who sees them | `product-surface.md` |
| HRMS sync, 15-minute status path, hierarchy, mid-journey fact changes | `hrms-sync-and-hierarchy.md` |
| Data loss, expedite, non-response clocks, mid-journey closure | `resilience-urgency-and-closure.md` |

Feature files under `<module>/` restate the rules that module owns. If a feature file or companion and the baseline disagree, `.ai-context/BRD.md` wins.

Gate review for every module is `.ai-context/GATE.md`.
