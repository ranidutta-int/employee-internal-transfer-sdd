# Feature BRDs

Feature BRDs live here, grouped by module:

`.ai-context/brd/<module>/<feature-slug>.brd.md`

The authoritative baseline is `.ai-context/BRD.md` version 0.2. The member journey and the edge-case outcomes are `.ai-context/brd/end-to-end-journey.md`. A feature file restates the rules that module owns. If a feature file or the journey and the baseline disagree, `.ai-context/BRD.md` wins.

Gate review for every module is `.ai-context/GATE.md`.
