# Feature BRD: Movement execution

**Module:** transition  
**Status:** Draft, follows baseline v0.2

## Objective

After the chain approves, the movement type's checklist runs. The only task every type includes is confirmation that the HRMS accepted the new assignment. Other tasks exist only when that employer turned them on.
