# Test cases

When a spec is prepared for Gate 1, copy `.ai-context/templates/test_cases.template.md` to:

`.ai-context/test_cases/<feature-slug>.test_cases.md`

For BRD v0.1, the spec-derived scenarios sit inside each draft spec under **Spec-derived test design**. They are design notes, not executed tests. API-level cases are intentionally absent.
